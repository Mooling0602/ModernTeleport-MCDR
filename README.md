# ModernTeleport-MCDR

中文（简体）| [English](README_en_US.md)

ModernTeleport（现代化传送）是为 Minecraft 服务器设计的现代化传送插件，具有丰富的功能设计。借助 [MCDReforged](https://mcdreforged.com)，它可以通过原版的命令系统来兼容任意版本的 Minecraft Java 版服务器。

本插件**强制要求** Rcon 功能，你需要在 MCDReforged 配置好 Rcon 的连接信息，并确保在服务器启动完成后 Rcon 能够正常工作。另外，插件需要 MCDReforged 提供的实验性异步事件支持，以及一些新特性，因此你必须使用 MCDReforged v2.16.0 或更高版本。

> 推荐使用 `mcdreforged>=2.16.2`，v2.16.2 通过更新上游依赖版本修复了一些安全问题。
